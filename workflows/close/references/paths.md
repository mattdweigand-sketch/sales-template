# Close paths

The organization may rename or remove these example paths in policy.close.paths.
Each uses the same signature, evidence and exact-write safeguards.

- **new_business:** the agreement establishes a new customer relationship.
- **renewal:** the agreement extends an evidenced existing contract.
- **expansion:** the agreement adds evidenced scope to an existing relationship.
- **paid_pilot:** the agreement purchases a time-bounded evaluation. Preserve its
  actual charge and duration; do not substitute an annual contract or discount.

If no configured path fits, explain the mismatch and request the missing business
rule. There is no default org-creation, billing cancellation or subscription flow.

For an approved handoff, include deal/account links, the live deal state, agreement
reference, agreed scope/dates, the exact action requested and configured owners.
Include only the personal or commercial detail needed by that destination.
