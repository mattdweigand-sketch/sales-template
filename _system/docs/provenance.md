# Provenance

This seven-workflow Codex template was rebuilt from a user-supplied sales workflow
archive and the user's previous reusable template. The archive supplied the workflow
objectives and evidence/approval boundaries. The earlier template supplied portable
setup patterns and normalized coverage, hygiene, mail and forecasting mechanics.

The reusable distribution deliberately omits company-specific collateral, product
claims, pricing/targets, fonts, warehouse schemas, custom API fields, private flows,
customer observations and deployment identifiers. Pilot usage uses a generic
roster/activity/unit contract. Close uses signed terms and configured optional
downstream contracts. No organization-specific services are represented as installed.

Private deployment configuration and customer evidence are outside the tracked
source. The original inputs are separate and unchanged; they are not bundled here.
Code, examples and tests describe the current portable implementation, not live
production equivalence to a source deployment.

Pipeline presentation behavior was adapted from the subsequently supplied workflow
revision. The portable helper uses configured native record links, logical fields,
reporting settings and existing external runs. Source notifications and schedules
were replaced by chat status output. No source customer fixtures, collateral,
private identifiers or deployment settings were included.
